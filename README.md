- `/software/` — **เว็บไซต์ผลิตภัณฑ์ softlight** (ดีไซน์ชุดเดียวกับ HR Paper Mill): หน้าแรก `index.html` · รายการผลิตภัณฑ์ `products.html` · หน้า HR Paper Mill + แพ็กเกจและราคา `hr-paper-mill.html` (ราคาดึงจากระบบหลังบ้านของ HR Paper Mill › Dev Console › แพลน, ดาวน์โหลด PDF/PNG, ลิงก์ข้อเสนอ `?plans=&to=&off=&ref=&valid=&note=`) · สไตล์ `software/css/site.css` · สคริปต์ `software/js/`
- `/softlight/` — หน้า Portfolio และบริการของ softlight (`softlight/index.html` · `css/site.css` · `js/site.js`, ข้อมูลผลงานอยู่ใน `WORKS` ด้านบนของไฟล์)
- `/hr-paper-mill/` และ `/quotation/` อยู่ใน repo ของตัวเอง (GitHub Pages ใช้ repo นั้นก่อน จึงไม่ถูกส่งต่อ)
